#Global Travel Planner Website
Project Overview
The Global Travel Planner Website is a web platform designed to facilitate group travel planning and create a community-driven travel experience. The website allows users to explore past trips, join upcoming trips, vote on activities, create their own itineraries, and estimate travel costs. It also features AI-powered answers to travel-related questions and an easy-to-use system for organizing and promoting group trips.

Features
Homepage: A welcoming introduction to the travel group, with highlights of past trips and upcoming destinations. Features invitations to join special trips hosted by the site owner.
Past Trips Gallery: A collection of photos, videos, and blogs from previous travels, providing an interactive and visually rich experience.
Upcoming Trips: A calendar or list of upcoming group trips with trip details such as dates, destinations, activities, and estimated costs. Users can register to join these trips.
Activity Selection: A form where travelers can vote on activities they’d like to do, helping to shape the final itinerary.
Cost Estimator: A tool that calculates and breaks down estimated travel expenses, including flights, accommodations, activities, and group discounts.
Join the Trip: A registration section that allows users to sign up for upcoming trips and stay updated on travel details.
Contact & FAQs: A section for user inquiries and common questions, providing an accessible way to engage with site visitors.
Create Your Own Trip: A feature that enables users to create their own group trips, manage itineraries, and invite others to join.
AI Travel Assistant: An AI-powered feature that provides answers to specific travel-related questions about various countries.
Invite to Join: A dedicated section where the site owner can promote and invite people to join their specially planned trips, while encouraging users to create and share their own trips as well.
Technologies Used
HTML for structuring web content.
CSS for styling and layout design.
JavaScript for interactive elements and dynamic content.
AI Integration for providing country-specific answers to user questions.
